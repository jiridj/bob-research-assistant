## Usage Notes

This template is designed for executive audiences. Key principles:
- **Brevity**: Keep to 2-4 pages maximum
- **Clarity**: Use simple, direct language
- **Action-oriented**: Focus on decisions and next steps
- **Visual**: Use tables and bullet points
- **Impact-focused**: Emphasize business outcomes

**Pandoc Conversion**:
```bash
# Convert to Word
pandoc executive-summary.md -o executive-summary.docx

# With corporate template
pandoc executive-summary.md --reference-doc=executive-template.docx -o executive-summary.docx

# Convert to PDF
pandoc executive-summary.md -o executive-summary.pdf
```

**Presentation Tips**:
- Lead with the recommendation
- Use the "So what?" test for every point
- Anticipate questions
- Have backup data ready
- Practice the 5-minute version
