# PR-FAQ (Working Backwards)

> Purpose: Evaluate and refine an idea before committing resources by starting with the customer and working backwards.
>
> Audience: Executives, strategy leaders, product leaders, sponsors, and decision makers.
>
> Rule: Write as if the initiative has already launched successfully. Focus on customer outcomes, not implementation details.
>
> 📚 **Shared Resources**: See [_common-elements.md](_common-elements.md) for document metadata and Pandoc commands.

# PRESS RELEASE

> Maximum one page.
>
> Written for customers and external audiences.
>
> Focus on value, outcomes, and customer impact.
>
> Avoid jargon, technical implementation details, and feature lists.
